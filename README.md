# SQL Index Lab — ЛР5

Базовое SPA на React и TypeScript по теме «Симуляция выполнения SQL-запроса с разными типами индексов». Услуги — конфигурации B-tree, Hash и Bitmap для таблиц разных размеров. Внешний вид и компактные параметры ленты перенесены из ЛР2.

В ЛР5 реализованы **ровно две страницы**: плитка и лента. Все данные — из локальных mock-объектов. Бэкенд, PostgreSQL, Redis, S3/MinIO, интернет для медиа и авторизация приложению не нужны. Redux, собственный Context и `useOutletContext` не используются. Общие данные и обработчики передаются через props. React Router выполняет только маршрутизацию.

## Запуск

Нужны Node.js 22.12+ (либо совместимая более новая версия) и npm.

```powershell
cd C:\Users\User\GolandProjects\awesomeProject-LR5
npm install
npm run dev
```

Открыть http://127.0.0.1:3000. Изменения кода обновляются через Vite. Порт 3000 фиксирован: если он занят, остановите предыдущий запуск. Серверы остальных лабораторных запускать не требуется.

```powershell
npm run build    # TypeScript и сборка в dist
npm run preview  # просмотр собранного приложения, также порт 3000
npm run lint     # проверка кода
npm test         # браузерные проверки, без скриншотов и видео
```

При первом запуске браузерных тестов: `npx playwright install chromium`. Тесты запускают локальный Vite сами либо используют уже запущенный сервер ЛР5 на порту 3000.

## Страницы и элементы интерфейса

### Плитка — `/indexes`

- Заголовок «Индексы», краткая инструкция, счётчик найденных конфигураций и плитка из двух колонок.
- Поле «Название индекса» ищет по части названия, без учёта регистра и пробелов по краям.
- Ползунок «Размер таблицы»: все размеры, 100K, 1M, 10M.
- «Применить» применяет оба поля; Enter в поле названия также отправляет форму. «Сбросить» очищает фильтры.
- Карточка показывает изображение, название, размер таблицы, селективность и количество лайков. Нажатие открывает именно эту карточку в ленте.
- При отсутствии результатов выводится сообщение; произвольный прежний список вместо пустого не подставляется.
- У гостя нет кнопок удаления, добавления или постановки лайка.

### Лента — `/feed` и `/feed/:id`

Это одна страница с необязательным ID. Без ID отображается первая карточка текущей выборки. По ID можно открыть карточку напрямую и обновить браузер.

- Изображение, вертикальная область видео, название, описание и статус публикации.
- Компактные параметры справа: размер таблицы, селективность и число лайков. Сердце — показатель, а не действующая кнопка гостя.
- «Следующий» внутри кнопки со стрелкой открывает следующую карточку **отфильтрованного списка**. После последней снова открывается первая; при одной карточке показывается она же.
- «больше» раскрывает описание, «меньше» сворачивает. При смене карточки описание снова свёрнуто.
- Кнопка с иконкой паузы приостанавливает видео и позволяет возобновить воспроизведение. Автовоспроизведение без звука, с повтором.
- При пустой выборке или неизвестном ID выводится сообщение, «Сбросить фильтры» и ссылка «К плитке».

Переходы выполняются через React Router без перезагрузки документа; кнопки браузера «Назад» и «Вперёд» работают. Фильтры сохраняются между двумя страницами в рамках открытого SPA; при полном обновлении приложения сбрасываются.

## Нижнее меню

Навигация закреплена снизу колонки шириной до 390 px; прокручивается только содержимое страницы. На меньших экранах колонка занимает ширину и высоту экрана.

| Пункт слева направо | Доступность                | Действие                               |
| ------------------- | -------------------------- | -------------------------------------- |
| Лента               | Доступен                   | Первая карточка текущей выборки        |
| Добавление          | Недоступен                 | Настоящая disabled-кнопка без маршрута |
| Плитка              | Доступен                   | `/indexes`, с сохранёнными фильтрами   |
| Войти               | Недоступен, крайний справа | Настоящая disabled-кнопка без маршрута |

В меню четыре пункта, доступны только два. Самостоятельных страниц добавления и входа в ЛР5 нет. Неизвестные маршруты возвращают к плитке. Активный пункт подсвечивается и имеет `aria-current="page"`.

## Данные и медиа по умолчанию

`src/modules/mock.ts` — единственный источник карточек: девять объектов, три типа индексов × три размера таблиц. Поля совпадают с карточкой API ЛР4. `loadMockIndexes()` возвращает Promise с копиями объектов; HTTP-запросов к API нет. Все изображения и видео находятся в `public/media/` и запрашиваются только у самого Vite.

`IndexImage` подставляет `/media/default.png`, если `image_url` пуст, состоит из пробелов или изображение не загрузилось. `FeedMedia` аналогично подставляет `/media/default.mp4` при пустом или недоступном `video_url`. Если даже локальное видео невозможно воспроизвести, остаётся изображение. Нет циклического повтора загрузки сломанного дефолта.

Примеры для проверки:

| ID  | Карточка   | Пустые поля          | Ожидается                        |
| --- | ---------- | -------------------- | -------------------------------- |
| 5   | Hash 1M    | image_url, video_url | Изображение и видео по умолчанию |
| 8   | Hash 10M   | image_url, video_url | Изображение и видео по умолчанию |
| 9   | Bitmap 10M | image_url, video_url | Изображение и видео по умолчанию |

В Network видны только документы, JS/TS/CSS и локальные медиа. Запросов на порты ЛР2/ЛР4, к БД, MinIO или внешним API нет. В коде не оставлен запасной режим обращения к серверу.

## Используемые хуки

- `useState`: список и загрузка в `useIndexes`, применённые фильтры в App, черновик формы в IndexFilters, fallback медиа и состояние воспроизведения.
- `useEffect`: загрузка моков с очисткой флага подписки при размонтировании (в том числе в StrictMode); обновление заголовка вкладки в GridPage и FeedPage.
- `useRef`: ссылка на HTMLVideoElement в FeedMedia для паузы и воспроизведения.
- `useParams`: ID карточки из маршрута в FeedPage.
- `useLocation`: определение активной вкладки в TabBar.

Последние два — хуки React Router. Собственные провайдеры, `createContext`, `useContext`, `useOutletContext`, Redux и глобальное хранилище не нужны: данные передаются по дереву props, изменения — обратными вызовами.

## Проверки

Браузерные тесты проверяют две страницы и четыре пункта меню, фильтрацию, передачу выборки в ленту, замыкание «Следующий», пустые результаты, прямую ссылку и обновление, локальные дефолты и ошибки медиа, раскрытие описания и паузу, отсутствие сетевых обращений к бэкенду, сохранение нижней навигации и отсутствие горизонтального скролла при 1280×900, 390×844 и 360×640. Скриншоты, видео и трассировки не записываются.

Использованный стек и точные установленные версии — `package.json` и `package-lock.json`. Результаты расчёта аппаратных требований, ответы на контрольные вопросы и скриншоты в этот проект не включены.

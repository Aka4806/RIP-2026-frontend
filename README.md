# SQL Index Lab — индексы в БД

React-клиент для допзадания. Плитка запрашивает отфильтрованные данные страницами по 12 карточек. Лента получает карточки по их позициям в сессии Redis.

## Запуск

Сначала подготовь и запусти [бэкенд из ветки `dop-indexes`](https://github.com/Aka4806/RIP-2026-backend/tree/dop-indexes). В корне фронтенд-репозитория выполни команды.

```powershell
npm ci
npm run dev
```

Открой [SQL Index Lab](http://127.0.0.1:3009/). Vite проксирует `/api` на `127.0.0.1:18087`, а `/s3` — на `127.0.0.1:9000`.

## Демонстрация

1. На плитке выбери размер `1M`, введи `Hash`, нажми «Применить» и открой страницу 2. Плитка покажет 160 совпадений и 14 страниц. В Network → Fetch/XHR запрос содержит `table_size=1000000`, `name=Hash`, `page=2` и `limit=12`.
2. В терминале бэкенда выполни `.\run.ps1 bench`. Сравни медиану запроса с индексом и без него.
3. В свежем приватном окне открой приложение. Скопируй cookie `sql_index_feed` и проверь через Redis `ZCARD`, что в сессии 100 карточек.
4. В том же окне открой [позицию 100](http://127.0.0.1:3009/feed?position=100) и нажми «Следующий». На карточке появится № 101, а `ZCARD` — 200. Команды Redis есть в README бэкенда.

Спецификация API хранится в `scripts/swagger.json`. После её обновления выполни `npm run generate-api` для пересборки Axios-клиента.

# SQL Index Lab ЛР6

React / TypeScript, Redux Toolkit, Redux Thunk, Axios, React-Bootstrap и Vite.

Четыре страницы: плитка, лента, добавление и вход. API — бэкенд ЛР4 с JWT и Redis blacklist.

## Запуск

В отдельном терминале запустите бэкенд из папки awesomeProject-LR4:

```powershell
.\run.ps1
```

Для бэкенда нужны PostgreSQL, MinIO и Redis с настройками ЛР4. Пользователь создаётся методом регистрации в Swagger ЛР4.

Из папки awesomeProject LR6:

```powershell
npm install
npm run dev
```

Открыть http://127.0.0.1:3006. Требуется Node.js 22.12+.

Vite проксирует `/api` на http://127.0.0.1:18084 и `/s3` на http://127.0.0.1:9000. Префикс `/s3` удаляется перед передачей в MinIO. URL файлов из API преобразуются в адреса этого прокси с сохранением пути и имени объекта. Для другой машины задайте API_TARGET и S3_TARGET в локальном `.env` и перезапустите Vite.

## Страницы и действия

- `/indexes` — плитка, поиск по названию, выбор размера таблицы, применение и сброс фильтра. Размер передаётся в API параметром table_size. Поиск по названию дополнительно выполняется на клиенте, поскольку API ЛР4 поддерживает фильтрацию только по размеру. У собственных карточек авторизованного пользователя есть кнопка удаления.
- `/feed` и `/feed/:id` — лента, видео, описание, параметры и кнопка следующей карточки. Следующая карточка запрашивается через API с next=true. Авторизованный пользователь может поставить и отменить лайк.
- `/add` — создание черновика с названием, изображением и видео. Существующий черновик загружается с сервера. После создания заполняются описание, размер таблицы и селективность, затем выполняется публикация. Можно удалить черновик.
- `/login` — ввод имени и пароля. После входа в меню появляется «Выход» и доступно добавление.

Во время запросов отображается индикатор загрузки. Интерфейс блокируется для повторных нажатий. Ошибки показываются над содержимым страницы.

## Redux и авторизация

`src/store/index.ts` содержит состояния пользователя, фильтров, списка, ленты, черновика, загрузки, ошибок и режима mock. Фильтры сохраняются при переходах между страницами. При выходе фильтры сбрасываются.

Запросы конфигураций выполняются через createAsyncThunk и сгенерированный Axios-клиент. Вход и выход используют Axios напрямую и обычные Redux actions.

JWT хранится в localStorage под ключом sql-index-jwt. После F5 Redux инициализируется состоянием гостя, JWT остаётся в localStorage. Для возвращения пользовательского интерфейса нужно снова войти. В состоянии гостя сохранённый JWT автоматически к запросам не добавляется.

При успешном выходе сервер отзывает JWT через Redis, локальный токен удаляется. При ошибке выхода показывается сообщение, чтобы пользователь мог повторить запрос.

## Работа без бэкенда

Когда сервер недоступен, гость получает плитку и ленту из mock-объектов. В интерфейсе отображается сообщение о демонстрационных данных. Авторизованные запросы сообщают об ошибке подключения.

Медиа моков лежат в public/media/user. При отсутствии медиа используются public/media/default.png и default.mp4. Данные сервера используют файлы MinIO через прокси.

## Кодогенерация

```powershell
npm run generate-api
```

`scripts/swagger.json` — копия спецификации бэкенда ЛР4. При изменении API замените её актуальным docs/swagger.json из бэкенда и повторите генерацию.

`scripts/generate-api.mjs` запускает swagger-typescript-api с httpClientType: axios. Для читаемых имён методов задаются operationId по теме конфигураций. В параметре ID ленты допускается строка, включая пустую строку для `/api/feed/`.

Результат — src/api/Api.ts. Этот файл генерируется автоматически.
